## Консольное приложение с прогнозом погоды

Приложение заходит в интернет, берет данные о погоде из открытого источника и выводит их в консоль.
А также дает советы взять зонт или одеться потеплее.

В тестах использует Mockito для имитации выхода в интернет, когда надо проверить работу функционала без реального выхода.
